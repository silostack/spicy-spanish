# planning/ — designs, plans, and deploy runbooks

Dated work records for the workflow in the root `CLAUDE.md`. **Not living docs.** Living
documentation stays in `docs/` and the root `CLAUDE.md`.

| Path | From | Name | Purpose |
|------|------|------|---------|
| `design/` | `brainstorm` | `YYYY-MM-DD-<slug>-design.md` | Approved design. Shape: [`docs/guides/design-document-guide.md`](../docs/guides/design-document-guide.md). |
| `plans/` | `write-plan` | `YYYY-MM-DD-<slug>-plan.md` | Execution plan, same slug as the design; the progress log while `exec-plan` runs. Shape: [`docs/guides/exec-plan-contract.md`](../docs/guides/exec-plan-contract.md). |
| `deployment/` | `deploy-steps` | `YYYY-MM-DD-<slug>-deployment.md` | Copy-pasteable production runbook. Does not deploy. |
| `changelog.md` | `finish` | — | Student-, tutor-, or admin-visible feature additions, newest first. |

Designs and plans written before this workflow remain in `docs/plans/`.
